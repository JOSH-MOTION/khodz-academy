
# Khodz Academy — Python Fundamentals for Beginners
### Curriculum Overview

**Duration:** 1 Month (4 weeks)
**Classes:** 3 per week, 12 lessons total
**Prerequisite:** None — designed for absolute beginners with no prior coding experience
**Format:** Instructor-led live class + independent practice between sessions

**Course Goal:** Students learn Python from scratch and build practical console applications while developing genuine problem-solving skills — not just syntax memorization. This course is explicitly designed as the **foundation** for Khodz Academy's future tracks in Machine Learning, AI Engineering, Data Science, Backend Development, and Automation.

---

## 1. Course Philosophy

This course teaches students to **think like programmers**, not just recite Python syntax. Every lesson pairs a set of concepts with a mini project that uses them in a realistic, complete program, and every lesson explicitly builds toward a portfolio students can point to.

Two ideas run through the entire course:

- **Problem-solving over syntax memorization.** Concepts are taught by first framing the problem they solve, then showing the Python tool that solves it — so students learn to reach for the right tool when faced with a new problem, not just recognize syntax they've seen before.
- **Forward compatibility.** Every lesson calls out, where genuinely relevant, how the concept reappears in Machine Learning, AI Engineering, Backend Development, or Automation — so students see this course as a foundation, not an isolated unit.

---

## 2. Learning Outcomes

By the end of this course, students will be able to:

1. Understand Python syntax and core programming concepts.
2. Solve problems using variables, loops, functions, and conditionals.
3. Work with Python's built-in data structures (lists, tuples, dictionaries, sets).
4. Read from and write to files, including basic CSV handling.
5. Handle errors gracefully using `try`/`except`/`else`/`finally`.
6. Use external Python packages from the standard library and beyond.
7. Consume REST APIs and work with JSON data.
8. Build practical, complete console applications.
9. Debug Python programs effectively using tracebacks and systematic techniques.
10. Write clean, reusable, and maintainable code.
11. Build a portfolio of beginner Python projects.
12. Be well prepared for advanced courses such as Data Structures & Algorithms, Machine Learning, AI Engineering, Automation, and Backend Development.

## 3. Technology Stack

| Layer | Tools Taught |
|---|---|
| Language | Python 3 (latest stable version) |
| Editor | VS Code with the Python extension |
| Package Management | `pip`, the standard library |
| Standard Library Modules | `random`, `math`, `datetime`, `os` |
| Third-Party Packages | `requests` |
| Data Formats | Plain text files, CSV, JSON |
| Debugging | Reading tracebacks, `print`-based debugging, VS Code debugger basics |

**Explicitly out of scope for this course:** object-oriented programming (classes — introduced as a bridge topic in Lesson 12's "preparing for Machine Learning" discussion, but not taught in depth), web frameworks (Flask/Django), data science libraries (pandas/NumPy), databases, automated testing frameworks. These are covered in Khodz Academy's later, more advanced tracks that this course explicitly prepares students for.

## 5. Weekly Cadence (example)

Classes on **Mon / Wed / Fri**, roughly 1.5–2 hours per session. Homework between sessions: 1.5–3 hours, scaling up slightly as the course progresses.

---

## 6. Assessment Approach

- Mini-project completion after every lesson, demoed briefly at the start of the following session.
- Homework projects reinforce and extend each lesson's concepts independently.
- Continuous code review during in-class exercises.
- Final Capstone (Lesson 12): a complete, original console application chosen from five options, assessed on correctness, use of course concepts (data structures, functions, error handling, file persistence), code cleanliness, and debugging ability.

---

## 7. Required Tools (Student Setup)

## 9. Preparing for What Comes Next

This course is explicitly the on-ramp to Khodz Academy's advanced tracks:

- **Data Structures & Algorithms** — builds directly on Lessons 6–7's lists, tuples, dictionaries, and sets.
- **Machine Learning / AI Engineering** — builds on Python fluency, functions, and data handling from this entire course; Lesson 12 introduces a first glimpse of classes/objects as a bridge concept.
- **Backend Development** — builds on Lessons 8–11's file handling, error handling, and API consumption, extended later into building APIs rather than just consuming them.
- **Automation** — builds directly on Lessons 10–11's modules, `os`, and `requests` usage.
