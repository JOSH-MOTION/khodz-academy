
# Khodz Academy — React Development Bootcamp
### Curriculum Overview

**Duration:** 2 Months (8 weeks)
**Classes:** 3 per week, 24 sessions total
**Prerequisite:** Frontend Development Foundations (or equivalent: solid HTML, Tailwind CSS, JavaScript fundamentals, DOM, APIs, Git/GitHub)
**Format:** Instructor-led live class + independent practice between sessions
**Outcome:** Students go from vanilla JS developers to confident React developers who can build, style, route, manage state in, and deploy real multi-page web applications.

---

## 1. Course Philosophy

This course builds directly on Frontend Foundations. Every concept introduced connects back to something students already know:

- Components are "the div/section thinking" from Lessons 2–3 of Frontend Foundations, formalized.
- `useState` is the DOM state-toggling pattern from Lesson 6 (dark mode, modals, sidebars), now handled by React instead of manual class toggling.
- `useEffect` + fetch is Lesson 7's API work, now wired into React's component lifecycle.
- Routing replaces multi-page `.html` files with a single-page app that *feels* multi-page.

The course stays **project-based and practical** — every session ends with working code, and every week ends with a shippable mini project.

---

## 2. Learning Outcomes

By the end of this course, a student will be able to:

1. Set up and structure a modern React project with Vite.
2. Write JSX confidently and understand how it compiles to real DOM.
3. Build reusable, well-composed components with props.
4. Manage local component state with `useState` and handle events the React way.
5. Conditionally render UI and render dynamic lists safely with keys.
6. Build controlled forms in React.
7. Style React apps with Tailwind CSS, including reusable styled components.
8. Use `useEffect` to manage side effects, including data fetching.
9. Handle loading, error, and empty states in real API-driven apps.
10. Implement client-side routing with React Router, including nested and dynamic routes.
11. Share state across components with Context API.
12. Write and use custom hooks to extract reusable logic.
13. Perform full CRUD operations against an API from a React app.
14. Understand authentication concepts and implement protected routes.
15. Plan, build, debug, and deploy a complete capstone React application.

---

## 3. Technology Stack

| Layer | Tools Taught |
|---|---|
| Tooling | Vite (project scaffolding, dev server, build) |
| UI | React (function components, JSX, hooks) |
| Styling | Tailwind CSS (carried over from Frontend Foundations) |
| State | `useState`, `useEffect`, `useContext`, custom hooks |
| Routing | React Router (v6+) |
| Data | REST APIs, `fetch`, async/await, basic CRUD |
| Auth | Authentication concepts, protected routes (client-side pattern; no backend build in this course) |
| Deployment | Vercel |
| Version Control | Git & GitHub (continued from Frontend Foundations) |

**Explicitly out of scope for this course:** building a real backend/database (that's Module 3 — Backend Development), advanced state managers (Redux/Zustand), TypeScript, Next.js, testing frameworks. These belong to later, more advanced tracks.

## 5. Weekly Cadence (example)

Classes on **Mon / Wed / Fri**, roughly 1.5–2 hours per session (shorter, more frequent than Frontend Foundations' 2.5-hour twice-weekly format, since sessions here are more narrowly scoped). Homework between sessions: 2–3 hours.

---

## 6. Assessment Approach

- Weekly project completion, demoed at the start of the following week ("show and tell").
- Continuous code review during in-class exercises.
- Final Capstone (Week 8): a fully deployed, multi-page React application, assessed against a rubric covering component structure, state management, routing, API integration, styling, code cleanliness, Git history, and deployment.

---

## 7. Required Tools (Student Setup)

- Everything from Frontend Foundations (VS Code, Node.js, GitHub, Vercel account)
- Node.js (LTS) — required for Vite from Day 1
- React DevTools browser extension
