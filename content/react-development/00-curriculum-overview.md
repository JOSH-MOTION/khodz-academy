
# Khodz Academy — Frontend Development Foundations
### Curriculum Overview

**Duration:** 1 Month (4 weeks)
**Classes:** 2 per week, 8 lessons total
**Format:** Instructor-led live class + independent practice between sessions
**Outcome:** Students move from zero coding knowledge to being able to build, style, and deploy real responsive websites, add JavaScript interactivity, consume APIs, and work with Git/GitHub — fully prepared to start React afterward.

---

## 1. Course Philosophy

This course is **practical and project-based**. Every lesson ends with something the student built and can show. Theory is kept to the minimum needed to make decisions confidently — students are not asked to memorize syntax, they are asked to understand *why* something works so they can look up the *how* when needed.

Teaching order deliberately front-loads **HTML → Tailwind CSS → JavaScript**, skipping deep vanilla CSS, because:

- Utility-first CSS (Tailwind) is what most modern companies and freelance clients actually use.
- Students get visually impressive results fast, which keeps beginners motivated.
- Time saved on CSS theory is reinvested into JavaScript, DOM, and APIs — the concepts that actually gate a student from becoming "job-ready."

---

## 2. Learning Outcomes

By the end of the course, a student will be able to:

1. Explain how the web works (client, server, browser, HTTP, DNS) at a working level.
2. Write semantic, accessible HTML5 from scratch.
3. Style and lay out any interface using Tailwind CSS, including responsive/mobile-first design.
4. Build reusable UI components: navbars, footers, cards, buttons, forms, accordions, modals.
5. Understand core JavaScript: variables, data types, functions, arrays, objects, loops, conditionals.
6. Manipulate the DOM and handle browser events to build interactive UI (dark mode, dropdowns, carousels, sidebars).
7. Use `localStorage` for simple client-side persistence.
8. Understand REST APIs, HTTP methods, and JSON.
9. Fetch data asynchronously (`fetch`, `async/await`), handle loading and error states.
10. Use Git and GitHub for version control and collaboration.
11. Deploy a live website using Vercel or GitHub Pages.
12. Debug using browser DevTools and read technical documentation independently.
13. Use AI tools (like Claude/ChatGPT) responsibly as a learning aid, not a crutch.
14. Assemble a small portfolio of real, deployable projects.

## 3. Technology Stack

| Layer | Tools Taught |
|---|---|
| Markup | HTML5, semantic tags |
| Styling | Tailwind CSS (primary), core CSS concepts (box model, flexbox basics) only as needed |
| Logic | JavaScript (ES6+ fundamentals) |
| Browser | DOM APIs, events, localStorage |
| Data | REST APIs, JSON, Fetch API, async/await |
| Version Control | Git, GitHub |
| Deployment | Vercel and/or GitHub Pages |
| Editor | VS Code + essential extensions |

**Explicitly out of scope for this course:** React, TypeScript, backend/servers, databases, CSS preprocessors (Sass), build tools (Webpack/Vite internals). These are introduced in the *next* course in the Khodz Academy track.

| # | Lesson | Core Topics | Project |

| 8 | Professional Workflow + Final Project | Git, GitHub, README, deployment, DevTools, AI tools, docs | Final Business Website (deployed) |

## 5. Weekly Cadence (example)

- **Week 1:** Lesson 1 (Tue) · Lesson 2 (Thu)
- **Week 2:** Lesson 3 (Tue) · Lesson 4 (Thu)
- **Week 3:** Lesson 5 (Tue) · Lesson 6 (Thu)
- **Week 4:** Lesson 7 (Tue) · Lesson 8 (Thu) — final project presentation/demo day

Each class session is assumed to run **2–2.5 hours**, with a short break at the midpoint. Homework between sessions is designed to take **2–4 hours**.

---

## 6. Assessment Approach

No formal exams. Students are assessed through:

- Completion and quality of the mini project after every lesson.
- A short "show and tell" at the start of each class (2–3 min per student) where they demo their homework — builds presentation skill and accountability.
- Final project: a fully deployed business website, reviewed against a rubric (structure, responsiveness, styling, interactivity, code cleanliness, deployment, README quality).

---

## 7. Required Tools (Student Setup)

- A laptop (Windows/Mac/Linux)
- [VS Code](https://code.visualstudio.com/) with extensions: Live Server, Tailwind CSS IntelliSense, Prettier
- Google Chrome (or any Chromium browser) for DevTools
- A free [GitHub](https://github.com) account
- A free [Vercel](https://vercel.com) account (or use GitHub Pages)
- Node.js installed (needed from Lesson 2 onward for Tailwind CLI, if not using CDN/Play CDN)
